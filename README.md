# 🔥 HELLBREAK

**Кооперативный survival в стиле Vampire Survivors, только сложнее.**

Адские полчища демонов наступают. Ты и твои друзья (до 10 человек) должны продержаться как можно дольше. Автоматическая стрельба, прокачка, три типа врагов и постоянно растущая сложность. Смерть — это вопрос времени.

## 🎮 Геймплей

| Механика | Описание |
|---|---|
| **Движение** | WASD / стрелки |
| **Атака** | Автоматическая стрельба по ближайшему врагу |
| **Опыт** | Синие кристаллы, выпадающие из убитых врагов |
| **Прокачка** | При левелапе случайный апгрейд (6 видов) |
| **Сложность** | Растёт каждую минуту (скорость и HP врагов увеличиваются) |

### Враги

| Тип | Цвет | Скорость | HP | Опасность |
|---|---|---|---|---|
| **Демон** (обычный) | 🔴 Красный | Средняя | 20 | Низкая |
| **Бес** (быстрый) | 🟡 Оранжевый | Быстрая | 10 | Средняя (роем) |
| **Зверь** (танк) | ⚫ Тёмно-красный | Медленная | 80 | Высокая |

### Апгрейды (авто-выбор при левелапе)

| Название | Эффект |
|---|---|
| 🔥 Жгучая боль | +30% к урону |
| 🦇 Крылья демона | +15% к скорости бега |
| 😡 Бешенство | +20% к скорости атаки |
| 🛡 Толстая шкура | +30 к макс. HP + лечение |
| 💀 Пронзающая душа | +1 пробивание (проходит сквозь врагов) |
| 👁 Жадность | +50% к радиусу сбора кристаллов |
